## 🎯 Visão Geral do Projeto
O objetivo principal é aplicar aprendizado de máquina para triagem e suporte à decisão médica na saúde da mulher. A solução realiza a classificação de riscos e diagnósticos com base em exames e dados estruturados, permitindo identificar padrões críticos na saúde feminina.
